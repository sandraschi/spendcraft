# spendcraft v0.1.0

Expense claims for a small team. Local, one SQLite file. Windows x64.

## Downloads

- `spendcraft-app.exe`: the desktop window.
- `spendcraft.exe`: CLI and MCP server.
- `spendcraft-0.1.0-setup.exe`: per-user installer.
- `spendcraft-v0.1.0.mcpb`: MCP bundle.

## What is new

- UK HMRC mileage for tax year 2026 to 2027, and IRS business mileage for a 2026 trip date.
- The window menu is File, Edit, View, Window, and Help.
